Политика конфиденциальности

NLS: статус смены инициатора · обновлено 19 ноября 2026 года · разработчик Arsen Murzaliyev

Расширение предназначено для отображения статусов смены и поручений сотрудников ОТП 1 линии на страницах support.nls.kz и desk.nls.kz.

Какие данные используются

  • Из указанной Google Sheets-книги расширение загружает график: ФИО сотрудников, рабочее время, перерывы, цветовые поручения, коды отсутствия и примечания. Код «Н» может обозначать отсутствие или больничный; расширение не делает медицинских выводов.
  • На открытой странице NLS расширение читает необходимые для индикаторов ФИО инициатора, исполнителя и текущего пользователя, а для отметки подходящих заявок — их номер, время создания и статус. Содержимое комментариев клиентов и токены входа в NLS не используются.
  • Пользователь может сохранить ручные соответствия ФИО, тему оформления, частоту обновления и настройку ночных напоминаний.

Зачем и где данные хранятся

Данные используются только для показа индикаторов, проверки подходящих заявок и отправки выбранных уведомлений. Копия графика и настройки хранятся в локальном хранилище расширения в браузере. Имя текущего сотрудника и отметки о уже показанных уведомлениях хранятся во временном хранилище до перезапуска браузера или перезагрузки расширения. Данные графика заменяются при обновлении; после удаления расширения его локальное хранилище удаляется браузером.

Передача данных

Расширение обращается по HTTPS только к Google Sheets для загрузки одной указанной книги. Данные заявок NLS, локальные настройки и содержимое графика не отправляются разработчику, в аналитические сервисы, рекламным сетям или другим сторонним серверам. Расширение не продаёт данные и не использует их для рекламы. Системные уведомления формируются локально средствами браузера.

Управление данными и связь

Индикаторы и ночной режим можно выключить в меню расширения. Ручные соответствия ФИО можно изменить там же. Для удаления локальной копии графика и настроек удалите расширение в Chrome. По вопросам обращайтесь через контакт разработчика, указанный на странице расширения в Chrome Web Store.

Использование данных, полученных из Google Sheets, соответствует Chrome Web Store User Data Policy, включая требования Limited Use: данные применяются только для явно описанных функций расширения и не передаются для рекламы или иной несвязанной цели.
